# 🧟 Custom CS 1.6 Zombie Plague Server & Ecosystem

A modular, full-stack Counter-Strike 1.6 Zombie Plague game server architecture built from scratch. Designed as a high-performance custom game mode featuring server redirection, database integration, and a companion web dashboard.

## 🚀 Project Overview
This project moves beyond standard configuration by engineering custom server-side game logic, event hooks, and system architecture for HLDS (Half-Life Dedicated Server). 

## 🛠️ Tech Stack & Components
* **Game Server Engine:** HLDS (SteamCMD Windows Build)
* **Engine Metamod Bridge:** Metamod (Pants / ReHLDS ecosystem compatible)
* **Scripting Framework:** AMX Mod X (v1.10.
